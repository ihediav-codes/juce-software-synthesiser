# JUCE Software Synthesiser

A C++/JUCE software synthesiser developed as a university project.

The synthesiser is designed as an audio plugin and supports MIDI-controlled sound generation with multiple oscillator layers, ADSR envelopes, delay effects and stereo auto-panning.

## Features

* MIDI-controlled synthesis
* Multiple oscillator layers
* ADSR envelope control
* Delay effect
* Stereo auto-panning
* Real-time audio processing
* JUCE-based audio plugin architecture

## Technologies

* **C++**
* **JUCE**
* **Digital Signal Processing (DSP)**
* **MIDI**
* **Audio plugin development**

## Project Structure

* `Source/` — C++ source and header files for the synthesiser
* `AutoPanner.jucer` — JUCE project configuration
* `JuceLibraryCode/` — JUCE-generated project files

## About the Project

This project was developed as part of my BSc (Hons) Sound Engineering and Audio Technology degree at the University of Huddersfield.

It gave me practical experience working with C++, JUCE, real-time audio processing and the development of software-based musical instruments.
